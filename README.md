> [!WARNING]
> **Where is the source code?**
>
> It moved to [git.reseam.app/reseam-community/madkarma-patches](https://git.reseam.app/reseam-community/madkarma-patches).
> This GitHub repository is now only the issue tracker, because git.reseam.app does not allow sign-ups:
> **open patch requests and bug reports here**.

> [!IMPORTANT]
> If you added this bundle from GitHub, it will no longer update. Remove it in Reseam Manager
> (**Settings > Patch sources > madkarma-patches > Remove patch source**), then add it again with the
> **Add to Reseam** button at the top of this page.

> [!TIP]
> Want an app supported? [Open a patch request](https://github.com/madkarmaa/reseam-patches/issues/new?template=patch_request.yml).
>
> And hey, if you find this bundle useful, consider giving it a star, and maybe [donating to Reseam](https://reseam.app/donate/)
> or [to me directly](https://ko-fi.com/madkarma). It helps more than you might think :&#41;
